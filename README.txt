GarageDesk - Complete Clean Project

RUN:
1. Open this folder in VS Code.
2. Open terminal in THIS folder (the folder containing pom.xml).
3. Run: mvn spring-boot:run
4. Open http://localhost:8080

Included:
- Vehicle CRUD: create/read/update/delete
- Mechanic CRUD: create/read/update/delete
- Service Bay CRUD: create/read/update/delete
- Job card creation
- Date + time scheduling
- Bay conflict prevention
- Mechanic conflict prevention
- Job status workflow
- Billing
- Dashboard counts
- H2 file database

The ZIP root is the Maven project. Do not create another nested GarageDesk folder.
